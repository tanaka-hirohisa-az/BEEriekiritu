## 加工した点（これ以外は一切していない）

1. CHAR型の前後空白を除去（CHAR固定長のパディング）
2. タブ・CR・LFを半角スペースに置換（CSVの行が壊れるため。該当は売上実績の品目コード1件のみ）
3. DATE型を `YYYY/MM/DD HH24:MI:SS` の文字列で出力
4. NUMBER型を指数表記にならないよう固定小数で出力し、末尾の余分なピリオドを除去

## 結合するときに踏むと危ない点

**売上実績のキーは `F_在庫品目番号`、単価マスタのキーは `F_納入品目番号` で、この2つは一致しない場合がある。**
`04_TB_納入品目情報.csv` が両方を持つので、これを介して変換する。74,648行のうち 8,136行で両者が異なる。

2025年以降に売上のある「品目×得意先」8,889組のうち、単価マスタに該当があるのは 8,810組（99.1%）。内訳は在庫品目番号経由で 8,794組、納入品目番号での直接結合で 8,749組。**どちらか一方だけでは取りこぼす**ので、両方でフォールバックさせる。

ある売上日時点の登録単価は、その品目×得意先で `F_開始日 <= 売上日` を満たす最新の開始日のレコード。

## 売価の2系統

- **実績単価**: `01_TB_売上実績新情報.csv` の `F_単価`。実際にいくらで売ったか。
- **登録単価**: `02` / `03` の `F_契約単価`・`F_協定単価` ほか。得意先別にいくらで登録し、いつ改定したか。
