# 売上予算の入力手引き

Power BI レポート **売上予想** の「予算」は、PRONES に存在しないため Excel から取り込んでいます。
予算を変えるときはこのファイルだけを編集してください。

## 0. ファイルの場所

```
C:\PowerBI\売上予想\売上予算.xlsx
```

> ⚠️ **このフォルダから動かさないでください。**
> Power BI サービスからのスケジュール更新は、オンプレミスデータゲートウェイ
> （サービスアカウント `NT SERVICE\PBIEgwService`）がファイルを読める必要があります。
> OneDrive を含むユーザープロファイル配下（`C:\Users\...`）はこのアカウントから読めないため、
> ゲートウェイに読み取り権を付与したこのフォルダに置いています。
>
> このリポジトリの `data\売上予算.xlsx.OLD_使用しません` は移動前の残骸です。削除して構いません。

## 1. どこを編集するか

`売上予算.xlsx` を開き、**「予算」シートの黄色いセル**だけを編集します。
もう1枚の「入力の手引き」シートは説明用で、Power BI には取り込まれません。

| 列 | 入力するもの |
|---|---|
| `年月` | `YYYY/MM` の**文字列**。例 `2026/08`。日付書式にしないでください（`'2026/08` とアポストロフィを付けると確実） |
| `得意先区分` | `全社` / `日立系` / `コマツ系` / `コベルコ系` / `キャタピラー系` / `住友系` / `その他` / `社内売り` のいずれか |
| `予算金額` | 円。3桁区切りの表示書式は自由 |
| `備考` | 任意のメモ。Power BI には取り込まれません |

## 2. 二重計上を防ぐルール（重要）

**1つの年月には「全社」1行だけ、または区分別の行だけ、のどちらか一方**を入れてください。
混在させると Power BI 上の合計が二重になります。

- まだ区分別に割り振れていない月 → `全社` 1行でOK
- 区分別予算が決まった月 → その月の `全社` 行を**削除**して区分別の行に差し替える

例）2027年1月を区分別に切り替える場合

```
削除:  2027/01 | 全社     | 380,000,000
追加:  2027/01 | 日立系   | 120,000,000
       2027/01 | コマツ系 |  90,000,000
       2027/01 | コベルコ系 | 70,000,000
       2027/01 | その他   | 100,000,000    ← 合計が元の全社予算と一致するように
```

## 3. 月を増やすとき

「予算」シートの表の**最終行のすぐ下**に行を追加し、4列とも埋めてください。
Excelのテーブル「予算表」の範囲は自動で広がります。**空行を挟まないでください。**
Power BI 側のモデル変更は不要です。

## 4. 反映のしかた

1. `売上予算.xlsx` を保存する
2. **Power BI サービス**でセマンティックモデル「売上予想」を更新する
   （ゲートウェイ経由で読みに行くので、Desktop を開く必要はありません）

Desktop で確認したい場合は、`売上予想.pbip` を開いて「更新」を押してください。

## 5. パラメーター `予算ファイルパス`

取り込み先は Power BI Desktop の **[ホーム] → [データの変換] → [パラメーターの管理]** にある
パラメーター **`予算ファイルパス`** で指定しています。M式を触る必要はありません。

現在の既定値:

```
C:\PowerBI\売上予想\売上予算.xlsx
```

> このパスはローカルドライブなので、どのPCで開いても同じ文字列で通ります（ユーザー名を含まないため）。
> ただし **Power BI サービスからの更新は、このパスを読めるゲートウェイが動いているPC**
> （現在は 100172 のPC）に実ファイルがあることが前提です。
> 別PCでゲートウェイを動かす場合は、そのPCの同じパスにファイルを置いてください。

## 6. 「全社」を選んだときの見え方

得意先区分スライサーで `全社` を選ぶと、予算だけが表示され内示・確定は空になります。
これは異常ではなく、**その月の予算がまだ区分別に割り振られていない**ことを示しています。
区分別に差し替えれば、区分ごとに達成率が出るようになります。
